## Why this page exists

The audit of 1.0.6 ran on the TestFlight build commit `06cd6f6` before the
public tag existed; the public commit `ab64f15` was cut afterwards as a scrub of
that tree (development-only folders removed, comments reworded). The release
tag points at the scrub, so the [client drift check](../../tools/client_drift.py),
which keys a page on the tag's commit, found no page for `v1.0.6`. This page
pins the tagged commit and states the one fact that lets the audited build's
verdict carry: no non-comment line differs between the two trees. From 1.1.0
the audited commit is the tagged commit and no page of this kind is needed.
