**QUALIFIED PASS at this layer.** The delta from the audited base is a 17-line registrar auth hardening — probes authenticate, missing secrets fail loudly, probe bodies stay synthetic — with a pre-existing token-in-argv pattern extended to one more credential (INFO). Everything load-bearing was re-verified rather than carried on trust: the in-enclave build resolves only a digest-pinned base plus a fail-loud in-place patch and is byte-identical to the build cleared today on the sibling recipe; the engine command is 100% literal with `--log-requests-level 0`, a pinned `--trust-remote-code`, serve-revision = download-revision, and an explicit 1800 s watchdog on both replicas with no label asserting anything it doesn't do. The qualifications, in descending order of cost:

1. **Every plaintext service's stdout ships off-box unredacted** to `telemetry.infra.near.ai` via the recipe's own otelcol-contrib, send-queue persisted to a volume (HIGH, deployed ON) — the posture is conditional on print discipline in one engine build and one proxy build, whose known print-forcers are the next two items.
2. The engines' **unauthenticated `/configure_logging`** (CRITICAL on the engine base-image page) is reachable through allowlist-free `location /` nginx and the catch-all proxy on the flat network (MEDIUM, deployed ON).
3. **dcgm-exporter is tag-pinned** in a `SYS_ADMIN` all-GPUs container — bytes can drift under the attestation; the sibling recipe already digest-pins it (MEDIUM, deployed ON).
4. The splice channel can hand the E2EE terminator `WEB_CONTEXT_SEARCH_URL`/`FUSION_*` with no attestation-visible change (MEDIUM, deployed OFF — downgraded from the base's HIGH on proxy-source evidence).
5. The **watchdog hang-dump stays armed** at 1800 s on both replicas, on a config whose own header calls large-input EAGLE stability unvalidated (LOW, ARMED).

Recommend, in-file: digest-pin dcgm (copy the sibling's `@sha256:ed594cf5…`); front the engines with a path allowlist; add a scrub processor to the otelcol `logs/app` pipeline; bind the OTLP receivers to localhost or drop the unused traces/otlp pipelines; pass probe credentials via `--header @file` or env-fed config rather than argv.
