## Verdict

**Qualified PASS at this layer.** The file hands no logging switch to any engine or proxy, forces OHTTP on for both models, pins every model revision (and pre-fetches at those pins), keeps every telemetry destination literal, buffers no plaintext to disk at any hop, and the DeepSeek A/B is confirmed to diverge by a single privacy-neutral env var on a source-verified one-patch image. The qualifications, in descending order of cost to the end-to-end claim: **(1)** the engines' unauthenticated `/configure_logging` (CRITICAL on all three engine pages) is reachable both from the flat network this file joins and — for the dsv4 replicas — through the front door, because the `b0c5cd07` proxy forwards any path; a path allowlist in nginx or the proxy would close it and neither exists; **(2)** harness-C3 — everything any service here prints leaves the TEE twice, unredacted, including to a third-party US SaaS on this node, so the posture is conditional on per-image print discipline (and on no 30-minute hang, given `--watchdog-timeout 1800` + the watchdog dump HIGH); **(3)** the `/compose/up` splice channel can set `DSV4_RETURN_HIDDEN_STATES` and `WEB_CONTEXT_SEARCH_URL` with no measurement change; **(4)** the weight downloader resolves `huggingface_hub` unpinned from PyPI inside the enclave. Recommend, in-file: front the engines with a path allowlist (nginx `location` allowlist or proxy-side); pin the downloader (`uvx --from 'huggingface_hub[hf_xet]==<ver>'` or vendored wheels); mirror gpu26's `swappiness=0` into this node's measured layer.

**Unverifiable at this layer (hand-offs):** whether this `file_sha256` matches the signed action log's current entry (local capture; not re-fetched live); whether `/compose/up` env splices surface in the signed action log (compose-manager source pages); engine print discipline at the configured levels, and the exact `/configure_logging` and watchdog behavior (engine source pages — load-bearing under C3); proxy internals including the no-allowlist forwarding and web-search fail-closed behavior (proxy source pages, relied on above); PyPI state on deploy day for the downloader; whether the guest has a swap device (guest-OS leg); dcgm-exporter bytes under its mutable tag.
