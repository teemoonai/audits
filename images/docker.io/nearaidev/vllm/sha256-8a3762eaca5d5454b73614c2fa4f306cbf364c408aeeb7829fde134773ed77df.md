### INFO (deployed: ON) — prefill/decode disaggregation: KV state moves between the engines of one pair over NIXL/UCX inside a pair-private network and IPC namespace of the CVM; the handshake listens on localhost; nothing crosses hosts, nothing is encrypted in software, and the decode engine trusts the KV-transfer parameters it is given

What crosses, read in the connector (`NixlConnector`, pull mode; `kv_role` `kv_producer` on prefill, `kv_consumer` on decode, `:280`): the router sends the request to a prefill engine with `max_tokens=1` and `kv_transfer_params={"do_remote_decode": true}`; the prefill engine returns `kv_transfer_params` holding its engine id, request id, block ids, `remote_host` = `VLLM_NIXL_SIDE_CHANNEL_HOST` and `remote_port` = side-channel port + DP index (`nixl/pull_scheduler.py:281-292`; `nixl/base_scheduler.py:76-79`); the router posts the client's body plus those parameters to a decode engine, which handshakes with the prefill engine and **reads the prefill's KV blocks** — state derived from the whole prompt, plaintext-equivalent — and generates from them.

- **Transport.** The handshake is a ZMQ `ROUTER` socket bound to `tcp://<side_channel_host>:<port>` (`base_scheduler.py:325-335`, `:355-357`; bind in `nixl/utils.py:42-51`); the host defaults to `localhost` (`envs.py:244`) and is not set, so it listens on the loopback of the pair's shared network namespace, ports 5600-5601 (prefill) and 5700-5701 (decode). - **Logs.** The connector's lines above DEBUG print engine ids, request ids, hosts, ports, block counts and a ten-entry block-id sample (`nixl/base_worker.py:1442-1491`, `_log_failure`), never KV contents or tokens; the one that prints a params dict is in the LOW finding above. Patches 22 and 23 add two static INFO lines (`base_worker.py:800-803`, `:815`) and a `ValueError` that echoes the operator's `enable_prog_thread` value (`:810-813`). UCX at `UCX_LOG_LEVEL=info` with `UCX_PROTO_INFO=y` prints its protocol-selection tables to stdout (transports, sizes); I did not read UCX.

The router recipe r2 drops any client-supplied `kv_transfer_params` (also inside `vllm_xargs`) and forwards only what the prefill engine returned (`router.py:363-366`, `:404-419`). That stripping — outside this image — is what keeps a client from choosing a `remote_request_id` or block ids; I did not trace whether a prefill engine would refuse a read of blocks that belong to another request (`nixl/pull_worker.py:161` declines an expired read; the rest not read). `VLLM_TRUST_REMOTE_PREFILL_CACHED_TOKENS=1` (patch 08) only lets the decode engine report the prefill's cache count.

### Verdict

**QUALIFIED PASS, for an image that runs on one of the two GLM-5.3-Flash CVMs whose logs are in the evidence.** The class follows the rule of this lineage, stated so a reader can disagree: a sink that only a malformed or non-standard client request, an internal inconsistency or a crash can trigger is ARMED and does not set LEAKS. A reader who counts any client-reachable trigger would call this page LEAKS, conditionally, on the chat parser's warning alone.

What the delta shows: this image is `79625e1f` plus four files, all in the GLM model and the NIXL agent set-up, none of which adds a content sink; the patched sources in the published image are the files reviewed. What is new is the deployment: a different model, a multimodal one on the HF renderer, split into prefill and decode engines that pass plaintext-equivalent KV state to each other. That transfer stays inside a pair-private namespace of the CVM — loopback for the handshake, CUDA IPC for the data — and the engines' network has no route out, which removes the phone-home and the media fetch as egress in practice. The qualifications are the upstream stdout lines this series leaves in place, unredacted on their way to telemetry.

**Residuals.** The router's stripping of client `kv_transfer_params`, the proxy's inlining default, the internal network and its probe, and the GPU confidential-computing mode are what keep the P/D and media paths closed, and all are outside this image; the base image beyond the 39 patched files rests on a builder-asserted label; native NIXL/UCX were not read; telemetry retention is outside source.
