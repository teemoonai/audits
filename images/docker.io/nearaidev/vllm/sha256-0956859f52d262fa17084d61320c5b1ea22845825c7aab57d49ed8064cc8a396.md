### Verdict

**QUALIFIED PASS** — no exfiltration path for chat plaintext at the deployed flags in normal operation; two qualifications, both carried from the audited build (this one precedes it by a day and by two patches). What this build lacks relative to `5eaa0d46` is code that moved Engram and input data between host and GPU more safely under confidential computing; its absence leaves those bytes in in-enclave pinned host memory read by the GPU, with no file, log or socket — a correctness and availability problem the operator fixed the next day, not a privacy one. Request/response logging is opt-in and off; the response-body middleware, dev and RL routes, runtime LoRA loading, profiler, tracing, Cohere API and scale-out routes are gated at process start by values the attested compose leaves unset; there is no runtime logging switch; disk artifacts are config-keyed; the KV cache has no CPU or disk tier; metrics and access logs are aggregate; the three patches are arithmetic and gating with no sink. The crash-path history leak of v0.12.0 remains closed; the draft-token residue it still prints is up to three ids per request. This page describes a superseded engine: its ranks were evicted on 2026-10-31 by the re-up of their own recipe file, and nothing runs this image today.

**Residuals.** Image↔source correspondence for everything but three files rests on labels and the attested build of a Dockerfile that `FROM`s a digest; native components were not read; the proxy may or may not bound the media finding; enclave egress policy and telemetry retention are outside source; the eviction mechanism rests on the orchestrator's reading of compose-manager, not on this page's own.
