# SGLang inference engine (GLM-5.3-Flash, near.ai fc91d24 build) — Privacy Audit

> Part of the near.ai inference-path privacy audit. Method: [/notes/method.md](/notes/method.md).

**Image:** `nearaidev/sglang@sha256:a7b7136abcf5e07522289d96e96fec9b42a1a30f9dfda57e957f142680d2d67b`
**Source:** `PierreLeGuen/sglang-upstream` @ `fc91d2403cc210a86bd5fc715c6609f58c932e5a` for the entire `python/sglang` tree (the Dockerfile does `rm -rf /sgl-workspace/sglang`, unpacks the tarball there, and `pip install --no-deps --no-build-isolation -e python`, so the running package is this tree, not the base's).
**Role:** the inference engine — the one process legitimately entitled to see message plaintext. It sits behind `nearaidev/vllm-proxy-rs` (the E2EE/OHTTP terminator, `OHTTP_ENABLED=true`, recipe line 271) behind nginx (bare `location /` at 1148–1150 and 1170–1172); engine port 8000 is not host-published but is reachable on the `external: true` shared Docker network `dstack_default` (recipe 512–515).

**Verdict:** At the deployed launch flags, request logging is off and pinned to its safest level (genuinely consumed on this path), request/crash dumping is off, no engine telemetry is emitted, Prometheus labels are content-free, the multimodal caches are in-memory, and nothing request-derived is written to the mounted volumes. But one deployed-ON path writes model output to the log in normal operation:

1. the **glm47 tool-call parser logs a model-emitted argument value verbatim at WARNING** when a numeric-typed parameter is not numeric (MEDIUM, deployed ON) — confirmed at `fc91d24`, identical to upstream `main`, on the parser this recipe selects, with no flag to suppress it;

and three paths keep the rest short of "cannot happen":

2. an **unauthenticated `/configure_logging` endpoint** (CRITICAL, deployed ON) — one POST turns on verbatim prompt+output logging and arbitrary-path request pickling, no restart; no `--api-key`/`--admin-api-key` in the deployed command, so the auth middleware is never installed;
3. a **watchdog hang-time dump** (HIGH, deployed ARMED) — full prompt and output token IDs of the in-flight batch at ERROR on an engine hang, undisableable, armed at the explicitly set **1800 s**;
4. a **request-driven media fetch** (MEDIUM, deployed ON) — GLM-5.3-Flash is multimodal, `--limit-mm-data-per-request '{"image": 64}'` caps the count but `--allowed-media-domains` is absent so any host is fetched; `file://` and absolute paths are read locally.

The amplifier: this recipe runs its own `otelcol-contrib`, which tails every container's json-file log and ships engine stdout verbatim to `https://telemetry.infra.near.ai` with no redaction stage (recipe 480–510, 664–665, 873–882, 910–911, 927–930). Finding 1 therefore terminates off-box, which is what makes the class LEAKS rather than PRIVATE.

### Verdict: LEAKS — narrowly, and otherwise private at the deployed flags on a signed-provenance build

At the flags actually deployed, I found one path by which response content reaches a log in normal operation: the deployed glm47 tool-call parser logs a model-emitted argument value verbatim at WARNING whenever a numeric-typed parameter is not numeric — a routine LLM formatting slip, no attacker, no config change, no flag to suppress it — and this recipe's own collector ships that line to `telemetry.infra.near.ai` with no redaction. The blast radius is one argument fragment per occurrence in tool-using traffic, which is why the severity is MEDIUM and not HIGH; it is still a deployed-ON write of plaintext to an off-box sink, which is why the class is LEAKS and not PRIVATE. This is the same finding the Phala page made for the engine this one replaces; it survives the replacement because the parser file is unchanged upstream and the fork does not touch it.

Everything else is the fleet's known posture, re-derived at these bytes: request logging off and pinned to its safest level (genuinely consumed on this path), request/crash dumping off, no engine telemetry, content-free metrics, in-memory multimodal caches, nothing request-derived on the persisted volumes, `--trust-remote-code` not set, and the near.ai delta — 13 small, readable commits — adds no sink. And "off" is not "cannot happen": the **unauthenticated `/configure_logging`** switch is present and unchanged (one POST turns on verbatim prompt+output logging and arbitrary-path pickling), the **watchdog dump** is undisableable at 1800 s, and the **media fetch** — live because GLM-5.3-Flash is multimodal — has an allowlist mechanism that defaults to empty and still reads local files.

On identity, this page is the opposite of its predecessor: the sglang python tree is bound by a signed GitHub attestation to a Dockerfile whose `ADD --checksum` pins a tarball I diffed clean against `fc91d24`. What that chain leaves builder-asserted is the upstream nightly beneath it — the compiled kernels the tree calls into — and that is where the next review should look.
