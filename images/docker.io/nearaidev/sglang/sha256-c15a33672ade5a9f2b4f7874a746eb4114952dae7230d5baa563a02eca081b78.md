### Verdict: PRIVATE at the deployed flags — the v8 tree plus one attention patch that is live everywhere and logs nothing

This image is the v8 build plus one patch to two attention files and one header package, and the claim that it is exactly that rests on the same chain of hashes the v6–v8 pages described — signed commit, workflow pins, `SHA256SUMS`, fourteen patch pins, manifest before/after hashes, a deterministic replay from a tarball I re-hashed — with one new exception: the `linux-libc-dev` package comes from Ubuntu's apt repository under apt's signature, not under a hash in the recipe. I say so, and it does not touch the request path.

What the new patch does, in privacy terms, is nothing: it pads a page table with `-1`, zero-fills a wider fp8 query buffer, copies KV into a wider row, and raises on shape mismatches with integers in the message. The brief and the recipe README call it flag-gated and inert; the fleet sets the flag, on all six replicas across ten hosts, so the Q8 prefill kernel — upstream code no earlier page had on the request path — now runs every prefill of every GLM-5.3-Flash request near.ai serves from this image. I read the python that feeds it and found no sink; I did not read the kernel. That is the leading new residual of this build, and it is a coverage statement, not a finding.

What the delta does not remove is everything the base pages found and the v8 addendum re-derived. No path at the deployed flags writes prompt text, reply text or token ids to a log, a file, a socket or an exporter in normal operation: the request logger is off at level 0, the content-bearing DEBUG lines need a level the deployed command does not set, the glm47 number-fallback WARNING cannot execute, and the sweep finds nothing new in a tree that is byte-identical to v8 outside two attention files. `/configure_logging` is still one unauthenticated POST away from verbatim prompt logging, now on ten hosts behind two proxy images. The watchdog still dumps the in-flight batch's token ids on a hang — 16 requests here, each up to a million tokens. The media fetch still has no allowlist. The ghost prefix cache is on everywhere, and the sidecar that receives its digests is this image. HiCache is on everywhere, which the v8 page's canary did not have: 325 GiB of pinned host RAM per replica holding finished conversations' KV and recurrent state until eviction, in memory only, behind storage gates that hold.

The method's PRIVATE condition, with this repo's standing qualifier — at the deployed flags, not "cannot happen" — and the residual set the sibling engine pages carry. **PRIVATE at the deployed flags.**
