### Verdict: PRIVATE at the deployed flags — the v10 tree plus one attention patch that is live everywhere and logs nothing, and four wheels that change no sink

This image is the v10 build plus one patch to one attention file and four hash-pinned wheels, and the claim that it is exactly that rests on a chain I walked end to end this time rather than taking the replay on report: the signed commit, the workflow's pins over the three control files, `SHA256SUMS` over the recipe, fifteen patch pins, 58 manifest before/after hashes, and a tarball I downloaded and hashed to the pin before applying the twenty patches myself. The one component still outside that chain is the `linux-libc-dev` header package, unchanged from v10.

What the new patch does, in privacy terms, is nothing: it asks the device how much memory is free, once, and thereafter slices one GEMM into row blocks when a prefill batch's logits scratch would exceed a budget. There is no log line, no file, no exception path, no fallback; the only new switch is a test aid that forces a block size. It exists because a v10 replica crashed in production on 2026-10-18, and it runs on every prefill of every GLM-5.3-Flash request near.ai serves from this image — fourteen engines on five CVMs. The wheels do not change where anything is written either; what pillow 13.0.0 changes is that the decoder a chat request can aim at — through an `image_url` the engine will fetch from any host, with no allowlist — no longer carries four known decode-time defects. I traced that path to the `Image.open` line; the recipe's own test exercises it; the recipe's README calls the model text-only, and I did not rely on that.

What the delta does not remove is everything the base pages found and the v10 page re-derived, printed line by line here: `/configure_logging` is still one unauthenticated POST away from verbatim prompt logging, on fourteen engines; the watchdog still dumps the in-flight batch's token ids on a hang — 64 requests at a time on the base tier, where the brief's argv does not apply; the media fetch still has no allowlist; stdout still leaves every CVM unredacted; the ghost prefix cache is on everywhere, and on two of the five CVMs its digests land in a sidecar running the previous image, created from a manifest three weeks older than the attested one. One of the base tier's eight replicas was created from a canary manifest no page covers. Four engines of this image may or may not still be running on a CVM that now serves a different model. None of those is a plaintext sink; all of them are things the attested manifests do not say.

The method's PRIVATE condition, with this repo's standing qualifier — at the deployed flags, not "cannot happen" — and the residual set the sibling engine pages carry. **PRIVATE at the deployed flags.**
