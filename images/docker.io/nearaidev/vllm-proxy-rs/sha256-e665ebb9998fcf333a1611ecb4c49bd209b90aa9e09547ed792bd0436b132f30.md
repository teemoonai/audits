### Verdict: QUALIFIED PASS — the delta adds no plaintext sink; the DP-affinity key is a salted digest confined to memory; the diagnostics emit only bounded labels; the two client-opt-in egress features carry over unchanged

On the path every ordinary chat request takes — OHTTP decapsulation → field decryption → (new) salted prefix digest → vLLM with an integer rank header → encrypted response — this build does not log, persist, cache, or transmit message plaintext anywhere except to the inference engine.
